# Maintenance Log: 2026-08-15

## Summary of Operations
Upgraded the host operating system packages and NVIDIA GPU kernel driver on the **`haze`** inference workstation (`10.7.82.11`, ASUS Ascent GX10 powered by the NVIDIA GB10 Grace Blackwell Superchip with 128 GB Unified Memory). Upgraded the GPU kernel driver from the production baseline `nvidia-driver-580-open` (`580.173.02`) to the New Feature Branch `nvidia-driver-610-open` (`610.x`) to support modern CUDA 13 Blackwell container runtimes (such as NVIDIA NGC vLLM `26.07`).

---

## 1. Context & Root Cause Analysis
*   **Host**: `haze` (`10.7.82.11`), ASUS Ascent GX10 (NVIDIA GB10, aarch64).
*   **Workload**: vLLM OpenAI-compatible server running `Qwen/Qwen3.8-27B-FP8` via declarative ComposeFlux stack (`hosts/haze/compose.yaml`).
*   **Observed Behavior**: `vllm-qwen38` (`nvcr.io/nvidia/vllm:26.07-py3`) successfully loaded 28.51 GiB model weights and allocated 76.06 GiB KV-cache (1,084,757 tokens) on the GB10 GPU, but the REST API frontend (`APIServer`) failed with:
    ```text
    ERROR: This container was built for NVIDIA Driver Release 610.43 or later, but
           version 580.173.02 was detected and compatibility mode is UNAVAILABLE.
    UnicodeDecodeError: 'utf-8' codec can't decode byte 0xbf in position 181: invalid start byte
    ```
*   **Resolution**: Upgrade host driver from `580-open` to `610-open` to provide full ABI support for PyTorch 2.x JIT dynamic op discovery and Blackwell tensor acceleration.

---

1.  **System Package Refresh & Upgrade**:

2.  **NVIDIA Open Driver 610 Installation**:


